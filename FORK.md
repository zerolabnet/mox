# Сборка webmail-custom

Это форк [mjl-/mox](https://github.com/mjl-/mox). Рабочая ветка называется `webmail-custom`. В ней веб-почта на русском и английском и несколько правок отправки и сборки. Ветка `main` повторяет код автора и для работы не нужна.

Путь модуля в `go.mod` остаётся `github.com/mjl-/mox`. Так проще переносить новые коммиты автора.

## Забрать код

Клонируйте репозиторий. Ветка по умолчанию уже `webmail-custom`.

```
git clone https://github.com/zerolabnet/mox.git
cd mox
```

Готовые файлы Linux amd64 и Linux arm64 лежат в [релизах](https://github.com/zerolabnet/mox/releases). Имена файлов `mox-linux-amd64` и `mox-linux-arm64`.

## Собрать самому

Сначала соберите страницы.

```
make frontend
```

Потом бинарник. Для Linux amd64 команда такая.

```
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags='-s -w' -o mox-linux-amd64 .
```

Для arm64 замените `GOARCH=amd64` и имя файла на `mox-linux-arm64`.

## Взять новую версию автора

Удалённый репозиторий автора называется `upstream` и указывает на https://github.com/mjl-/mox.

```
git fetch upstream
git merge upstream/main
make frontend
```

Конфликт в `webmail/webmail.ts` решайте по списку в [webmail/BEHAVIOR.md](webmail/BEHAVIOR.md). Файлы `webmail.js`, `msg.js` и `text.js` после переноса соберите командой `make frontend`. Руками их не склеивайте.

## Что изменено

### Язык

В шапке есть выбор языка. Режимы **Авто**, **English** и **Русский**. **Авто** берёт первый подходящий язык из списка браузера. Выбор хранится в браузере. Смена языка перезагружает страницу.

Интерфейс веб-почты переведён на русский. Текст писем не переводится. Особые папки на экране называются Входящие, Отправленные, Черновики, Архив, Спам и Корзина. Имена этих папок в IMAP остаются английскими.

Образцы поиска, `Re:`, `Fwd:` и операторы поиска остаются английскими. Подсказка темы переводит слова внутри кавычек. Пример адреса в русском интерфейсе выглядит как `Иван <ivan@example.org>`.

Числа писем склоняются. «Выбрано 1 письмо», «Выбрано 2 письма», «Выбрано 5 писем». Для одного непрочитанного подсказка говорит «1 непрочитанное», для остальных чисел «N непрочитанных».

### Шапка и раскладка

Значок языка и кнопка автоматической темы без рамки и заливки. Между ними тонкая линия.

Меню аккаунта содержит **Аккаунт**, **Подсказки**, **Справка**, **Настройки** и **Выйти**. Ниже стоят три значка раскладки. Новый профиль открывается в раскладке слева направо. Узкое окно временно ставит раскладку сверху вниз и возвращает сохранённую, когда окно снова широкое.

### Список и письмо

Фильтры стоят одной прокручиваемой строкой. Сортировка остаётся справа.

На широком экране наведение на письмо показывает значки корзины и архива. В корзине вместо переноса стоит красное удаление. Над открытым письмом те же действия словами. **Ответить**, **Ответить всем**, **Переслать** и **Ещё** остаются словами.

После удаления, переноса в корзину или архива открывается следующее письмо вниз по текущей сортировке. Если следующего нет, открывается предыдущее.

Флаг письма красный, когда он включён. Повторной кнопки **Ответить** под письмом нет. Отмена перемещения стоит внизу справа.

Колонки флагов и возраста подстраиваются под содержимое. У развёрнутой цепочки в центре знак минус.

Окна **Написать** и **Ответить** на широком экране одной ширины. У них есть рамка и тень. На узком экране окно письма занимает экран без этой рамки.

Рядом с именем отправителя стоит круг с буквой. Если политика страницы позволяет, подгружается изображение с Gravatar.

Подчёркивание смешанной латиницы и кириллицы включает только одно слово, в котором буквы двух алфавитов стоят подряд.

### Отправка

Тема с кириллицей сохраняет пробелы между словами. Длинная тема переносится по уже существующему пробелу и после разбора совпадает с набранной. Символ перевода строки внутри темы не рвёт заголовок.

Исходящее письмо уходит текстом. Рядом уходит HTML того же текста. Знаки вроде `<` остаются текстом.

Цитата при ответе по-русски имеет вид «дата, имя написал(а):».

### Значок вкладки

Значок вкладки это конверт `webmail/favicon.png`. Число непрочитанных во Входящих рисуется на нём. При обрыве связи бледнеет сам конверт. Прозрачный фон остаётся прозрачным.

### Сборка

Каждый push в `webmail-custom` публикует релиз с двумя файлами, `mox-linux-amd64` и `mox-linux-arm64`. В тексте релиза есть коммит, дата и сообщение коммита отдельным пунктом списка.
